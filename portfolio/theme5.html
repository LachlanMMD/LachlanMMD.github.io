Theme 5 focused on content production and website redesign. Working in a group, we selected CHIMAERA Collective as the subject of the project and developed a new version of an existing website. Although the project differed slightly from the intended goal of working with an external company, it provided an opportunity to revisit an earlier project and evaluate it critically using the design, development and content production skills gained throughout the semester. The project combined research, photography, content creation and web development into a single redesign process.

Challenge

The goal of the project was to redesign an existing website while producing new content to support the final result. My group chose CHIMAERA Collective, a project I had already worked on previously. This created a different challenge than starting from scratch. Instead of developing a completely new concept, the focus was on identifying weaknesses in the original website and improving both the content and presentation. The project required us to rethink the structure, visual identity and user experience while creating new assets to support the redesign.

Process

The project began with an evaluation of the original website and a discussion of what could be improved. From there we developed a new visual direction and planned the content needed for the redesign. A large part of the process focused on content creation. We produced and edited photography, developed visual assets and refined the written content used throughout the site. By combining new content with a redesigned interface, the project became an opportunity to improve both the presentation and communication of the CHIMAERA brand.

Solution

The final result was a redesigned version of the CHIMAERA website that combined new content with a more refined visual identity and improved structure. The redesign aimed to communicate the collective's activities more clearly while creating a more cohesive and professional user experience. The project brought together many of the skills developed throughout the semester, including design, content production, photography, collaboration and front end development.

Reflection

One of the most valuable parts of this project was revisiting work that I had created earlier in the semester. Looking back at the original CHIMAERA website made it easier to identify weaknesses in both the design and implementation that I would not have noticed at the time. Although working with an external company would have provided a different perspective, the redesign process highlighted how much my understanding of design, content and web development had developed over the course of the semester.
