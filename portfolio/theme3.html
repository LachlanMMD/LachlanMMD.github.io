Theme 3 • UX/UI

Theme 3 introduced the full design process behind a website. For the first time, I was responsible not only for building a solution, but also for researching, planning and testing it before development began. The theme shifted my focus from learning technical skills to understanding how design decisions are made and evaluated.

Challenge

For this project I was tasked with designing and developing a website around a topic of my own choosing. I chose to create a website for CHIMAERA Collective, a creative community focused on events, music and artistic collaboration. Unlike previous projects, I was responsible for the entire process, from research and planning to design, testing and development. The challenge was creating a visual identity and user experience that reflected the collective’s creative nature while remaining clear and easy to navigate.

Process

The project began with research into similar creative organisations and event focused websites. From there I developed moodboards, wireframes and a visual direction that matched the identity of CHIMAERA. Using Figma, I created a clickable prototype before moving into development.

User Testing

To evaluate the prototype I conducted informal user testing sessions throughout the whole process, using their feedback to make improvements to the design and overall user experience.

Solution

The final result was a fully designed and coded website for CHIMAERA Collective. The site included a custom visual identity, responsive layouts and interactive elements that supported the collective's focus on creativity and community. Compared to previous projects, this assignment required a much broader workflow that combined research, UX design, visual design, user testing and front end development within a single project.

Reflection

This website is still used by CHIMAERA Collective today, although it is due for an update. This project gave me my first experience managing an entire web design process from concept to implementation. One of the biggest lessons was learning how much time is spent making design decisions before any code is written. User testing also showed me that ideas which seem obvious to the me are not always obvious to users. If I revisited the project today, I would spend more time conducting user tests and looking at ways to better integrate the name "CHIMAERA", so it's pronuciation and meaning are more clear to users.
