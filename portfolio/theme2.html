Theme 2 • GRUNDLÆGGENDE WEB

Theme 2 marked my first introduction to web development. Up until this point, I had very little experience working with code, making the theme an important foundation for the rest of the semester. Many of the concepts introduced here, such as page structure, styling and responsive layouts, became skills that I would continue developing throughout later projects.

Challenge

The objective was to build a multi page website using HTML and CSS while applying layout systems, visual hierarchy and responsive design principles. The biggest challenge was translating desktop layouts to mobile view while maintaining usability and consistency across all five pages.

Process

The primary focus of this project was translating an existing design into a functioning website using HTML and CSS. Since the wireframes and visual direction were already provided, the challenge was understanding how to structure content in HTML and apply CSS to recreate the intended layouts. Through the development process, I learned how to work with HTML, organize files and assets, and use CSS for layout, spacing and typography. I also gained my first experience adapting a desktop design for smaller screens and understanding how different elements behave across devices.

Solution

The finished result was a responsive multi page website built entirely with HTML and CSS. Through the project I learned the foundations of web development and gained practical experience translating a design into a functional website. This project provided the technical foundation for the more advanced projects completed later in the semester.

Reflection

This project taught me the fundamentals of HTML and CSS and gave me my first experience building a complete website. Looking back, many of the solutions are simple, and the navigation in mobile view is not complete. However, I am proud of the progress I made in learning the basics of web development and creating a functional website from scratch.

If I were to redo this project, I would focus more on improving the mobile navigation, creating visual borders between the indivual section and grids, creating a hierarchy that better guides the viewer through the page.
